# Kyankima Website Prototype Design

## Purpose

Create a static, mobile-first website prototype for Kyankima Women's Cooperative using the Section A content inventory and information architecture.

## Structure

The public site follows the IA:

```text
Home
About
Products
  Agriculture Products
  Handcraft Products
Health Tips
Gallery
FAQs
Contact
```

An additional `hosting.html` page is included as an academic submission support page. It is linked from the footer rather than the main navigation because it is not part of the cooperative's public user journey.

## Traceability

Each page includes visible traceability pills and `data-inventory` / `data-ia` attributes showing which inventory items and IA nodes informed the content and layout.

## Technical Approach

Use plain HTML, CSS, and JavaScript so the site can be opened directly in a browser and deployed to free static hosting without a build step.

## Design Deviation

The prototype includes placeholder SVG visual assets instead of real cooperative smartphone photos because the source photos were not available in the workspace. Before public launch, these should be replaced by compressed real product and member photos with consent and alt text.
